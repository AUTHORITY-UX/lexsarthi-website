Chat input

Use a service and jurisdiction explicitly. Keep context scoped to the task.

POST /api/chat
Content-Type: application/json

{"message":"Draft an AI inventory checklist","service":"governance","jurisdiction":"India","context":"B2B SaaS"}

Chat output

Outputs carry the selected service, jurisdiction, agents, and model metadata.

{"response":"…","service":"governance","jurisdiction":"India","agents_used":["…"],"model":"…","timestamp":"…"}

Auth input

Passwords are hashed server-side. Use the returned bearer token only over HTTPS.

POST /api/publication/auth/login

{"email":"operator@example.com","password":"at-least-10-characters"}

Newsroom output

Every public article exposes its authoring agent and editorial status.

GET /api/publication/feed?limit=6

{"articles":[{"title":"…","agent_name":"Nyaya-21","verification_status":"agent-draft"}],"total":1}
