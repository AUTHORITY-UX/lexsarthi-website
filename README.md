## Overview

**Unknown Verdict** is the world's first **sovereign Legal AGI** – a complete, offline-capable, privacy-first legal intelligence operating system. It combines:

- **500+ specialised legal agents**
- **32.5M pre-computed vector embeddings** from 14.7M Indian legal records
- **Offline-first architecture** (runs on laptops, Raspberry Pi, or cloud)
- **Zero data retention** – absolute privacy by design
- **Hybrid operation** – seamlessly switches between offline and online modes
- **Moat Intelligence** – self‑evolving agents, predictive analytics, IRAC reasoning
- **MCP (Model Context Protocol)** – tool‑use for legal research, court monitoring, document generation

## Quick Start

### Prerequisites

- Python 3.11+
- 8GB+ RAM (16GB recommended)
- 20GB+ disk space
- (Optional) GPU for faster inference

### Installation

```bash
# Clone the repository
git clone https://github.com/AUTHORITY-UX/lexsarthi-website.git
cd lexsarthi-website

# Install dependencies
pip install -r requirements.txt

# Download models
python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('law-ai/InCaseLawBERT')"
python -c "from transformers import AutoModelForCausalLM; AutoModelForCausalLM.from_pretrained('LiquidAI/LFM2.5-2.6B', trust_remote_code=True)"

# Place data files
cp /path/to/legal_vectors.zvec data/
cp /path/to/metadata.json data/

# Run the app
python app.py
```

### Docker Deployment

```bash
# Build
docker build -t unknown-verdict .

# Run
docker run -p 7860:7860 --env-file .env unknown-verdict

# Or with GPU
docker run --gpus all -p 7860:7860 --env-file .env unknown-verdict
```

### Hugging Face Spaces

The app is pre-configured for HF Spaces. Just push your repo:

```bash
git add .
git commit -m "Deploy Unknown Verdict v43.0"
git push
```

## Moat Intelligence

The Moat Intelligence Layer adds 32 self-evolving endpoints that turn Unknown Verdict into a **living, learning legal brain**.

### Core Capabilities

- **Self-Evolving Agents** – Agents learn from every interaction and improve over time.
- **IRAC Reasoning** – Issue, Rule, Application, Conclusion framework with precedent weighting.
- **Dynamic RAG** – Auto-chunking, semantic search, version control.
- **AI Judge Evolution** – Verdict delivery with feedback loops.
- **Predictive Analytics** – Outcome probability, settlement likelihood, cost estimation.
- **Emotion-Aware Analysis** – Detect sentiment and generate empathetic responses.
- **Strategy Generator** – Winning strategies with counterarguments.
- **IP Vault & Forensics** – Immutable audit trails and integrity verification.
- **Outcome-Based Pricing** – Case pricing based on predicted outcomes.
- **Auto-Publishing** – Generate articles, newsletters, social posts.
- **Marketplace** – Connect clients with lawyers and agents.

## MCP (Model Context Protocol)

Unknown Verdict implements the **Model Context Protocol** (MCP), providing a standardised interface for AI agents to use external tools.

### Available MCP Servers

| Server | Tools | Description |
|--------|-------|-------------|
| **LegalSearch** | `search_legal_corpus`, `get_case_details` | Legal research and precedent search |
| **CourtMonitor** | `check_new_judgments`, `get_latest_judgments` | Monitors court websites for new rulings |
| **DocumentGen** | `generate_legal_document` | Drafts contracts, petitions, notices |
| **ClientComm** | `draft_client_email` | Drafts professional client communications |
| **RAGServer** | `add_document` | Adds documents to the knowledge base |
| **AgentRegistry** | `list_agents`, `invoke_agent` | Agent discovery and invocation |
| **ThirdEye** | `get_system_status` | System monitoring and health checks |
| **DataExport** | `export_case_data` | Export legal data in CSV/PDF/JSON |

All MCP endpoints are available at `/mcp/*` and appear in the Swagger docs.
