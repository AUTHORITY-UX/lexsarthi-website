## 📌 Overview

LexSarthi Alpha v5.0 is a fully‑functional, production‑ready AI platform that combines **220 specialised agents** and **10 verification layers** to deliver accurate, context‑aware legal and financial intelligence. Built with a **zero‑retention privacy policy** (all data auto‑deletes within 24 hours), it is designed for professionals who demand both power and confidentiality.

---

## 🚀 Key Features

| Feature | Description |
| :------ | :---------- |
| **220+ Specialised Agents** | Domain‑specific AI experts covering Corporate Law, Criminal Law, Intellectual Property, Taxation, Finance, Compliance, and more. |
| **10 Verifiers** | Each response passes through Fact Check, Legal Citation, Compliance, Bias Detection, Language Consistency, Logical Coherence, Originality, Privacy Filter, Ethical Review, and Output Sanitisation. |
| **Zero Retention** | All queries, responses, and uploaded files are automatically deleted after 24 hours. No data is used for training. |
| **Multi‑Modal Input** | Text, PDF, DOCX, Images (OCR), and Voice Transcription (Speech‑to‑Text). |
| **Web Search (Privacy‑First)** | Toggle‑able web search using DuckDuckGo (no tracking, no profiling). |
| **Payment Integration** | Razorpay – supports ₹2 Lifetime (first 1000 users), ₹102/month Premium, ₹1011/month Enterprise. |
| **User Dashboard** | “My Usage” shows total queries, today’s count, agents used, and recent history. |
| **Enterprise Analytics** | Global stats (total users, queries, DAU, paid users) for enterprise subscribers. |
| **Referral System** | Generate and share referral codes; both referrer and referee get bonus queries. |
| **Agent Customisation** | Enterprise users can create and edit custom agents. |
| **Multi‑Language Support** | 10+ languages including Hindi, Bengali, Tamil, Telugu, Kannada, Malayalam, Marathi, Gujarati, Punjabi, and more. |

## 🛠️ Tech Stack

- **Backend:** FastAPI (Python), PostgreSQL (Neon), JWT authentication, Razorpay payments, APScheduler for auto‑delete.
- **Frontend:** Cloudflare Pages, HTML5, CSS3, JavaScript, Font Awesome.
- **Deployment:** Hugging Face Spaces (Docker), Cloudflare DNS.
- **Additional:** SlowAPI rate limiting, PyPDF2, python‑docx, Pillow, pytesseract, SpeechRecognition, httpx, puremagic.
